8. **HTML Entity & Character Escaper:** Fast utility to swap raw HTML code into safe entities (`&lt;`, `&gt;`, `&amp;`) for documentation embedding.
9. **URL Parameter Parser & Query Builder:** Breaks a messy, long tracking URL down into a neat, editable table of key-value query pairs.
10. **Base64 Image Encoder/Decoder:** Drag-and-drop an icon or image to instantly copy its data-URI string for CSS or inline HTML use.
11. **cURL Command to Fetch/Axios Converter:** Paste a terminal `curl` request; instantly get the equivalent JavaScript `fetch()` or Axios code block.

14. **SVG Path Optimization Viewer:** Paste raw SVG code, toggle precision decimal reduction, and see a live comparison of the file size savings and visual rendering.
15. **API Response Mock Data Generator:** A quick UI to define fields (e.g., name, email, random ID) and export a custom array of fake JSON data for testing.
16. **Color Palette Contrast Checker (WCAG 3.0):** Input hex codes to check accessibility contrast ratios for text and UI elements in real-time.
17. **Meta Tag & SEO Previewer:** Input your site title, description, and open-graph image to see exactly how it will look on Google, X, and Slack.
18. **GraphQL Schema Visualizer:** Paste a GraphQL schema definition to generate an interactive, searchable node map of your types and relationships.
19. **Diff Viewer & Code Compare:** Side-by-side text inputs that instantly highlight insertions, deletions, and inline differences between two blocks of code.
20. **RSA/AES Key Generator & Text Encryptor:** Generates secure key pairs locally in the browser using the Web Crypto API to encrypt or decrypt text blocks.
